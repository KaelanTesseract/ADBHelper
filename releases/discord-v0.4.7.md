## ADBHelper v0.4.7 is out! ✨

🗂️ **Find Daily actions faster**
The Daily editor now has **Rewards**, **Battles**, **Heroes**, and **Shop** tabs. Drag steps from any tab into your routine.

🌙 **Dream Realm**
Run it from the dashboard or as part of Daily. It defaults to **2 battles per run**, with an adjustable limit of **1–30**.

🎁 **More Daily rewards**
Collect rewards from friends, mail, Noble Path, Daily Quests, and Guild Quests.

⚔️ **Heroes and shopping**
Add affinity, hero levels, equipment, Emporium purchases, a Noble Tavern single pull, or Essence Swap. Emporium budgets start at zero.

🖼️ **Patch notes**
Release graphics can now appear in the in-app update dialog.

Update from the green icon beside **Settings** or download the Windows EXE from GitHub.

https://github.com/KaelanTesseract/ADBHelper/releases/tag/v0.4.7

Please include a screenshot of the game and the affected action when reporting an issue. Thanks to [ADBAutoPlayer](https://github.com/AdbAutoPlayer/AdbAutoPlayer) for the original workflow inspiration!
