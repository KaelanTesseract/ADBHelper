## ADBHelper v0.5.2 is out! 🔌

**Older MuMu Player found too**
ADBHelper now also finds older MuMu Player versions such as MuMuPlayer 6.

**Log explains connection problems**
After **Find devices** the log shows which adb is used, which MuMu port answered, and why a device is not ready (offline, unauthorized). Still no device? Please send today's log (**Settings → Log files → Open log folder**).

**Installer only**
Download **ADBHelper-Setup-x64.exe**. Existing copies update as usual from the green icon beside **Settings**.
