# ADBHelper 0.4.1

## Language settings

- ADBHelper now defaults to English. Choose **Deutsch** under **Settings → Language** to switch to German. The app applies the change immediately and remembers your choice across restarts and updates.
- The interface, charts, action settings, and app messages follow the selected language. The app displays GitHub release notes as published.

## Dura’s Trials

- Fixed Raid Treasure title recognition when OCR separates or omits the decorative initial. The stage overview and the Sweep dialog now identify the same trial.
- ADBHelper can set up to six daily sweeps per confirmation, limited by the remaining daily attempts. It verifies the stage cap, selected quantity, daily token icon, and total cost before confirming.
- Fixed the missing consumption count after a successful batch. ADBHelper recognizes **Sweep Complete** at the top of the results screen, dismisses the rewards, and checks the daily counter on the same stage before recording the batch.
- Emulator verification used a completed four-sweep Raid Treasure batch on stage 25. The corrected result handler closed the rewards and verified that the daily counter dropped from four to zero.

The README and release notes are now maintained in English.
