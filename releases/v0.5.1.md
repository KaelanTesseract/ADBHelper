# ADBHelper 0.5.1

ADBHelper now finds MuMu Player by itself, whichever version you use and wherever it is installed.

## Connecting to MuMu Player

- ADBHelper looks up where MuMu Player is installed in Windows and also searches the Netease folders on every drive. This finds **MuMu Player 12** (`MuMuPlayer-12.0\shell\adb.exe`), the newer MuMu Player and installs on other drives such as `D:`. You no longer need to enter an ADB path.
- The search runs every time ADBHelper starts, so it follows MuMu Player after an update or a move.
- ADBHelper now tries every usual MuMu Player port: 7555, 16384 and the ports of further MuMu Player 12 instances (16416, 16448, 16480), and 5555. Before, it only tried 7555, so MuMu Player 12 often showed no device.

If **Settings → Device connection** still shows no device, start MuMu Player first, then choose **Find devices**.

## Validation

- **170 automated tests passed**, together with formatting, Clippy, and license and advisory checks. New tests cover the MuMu Player folder layouts, reading the install folder from Windows, and the port order.

## Update

Click the green update icon beside **Settings**, review the patch notes, and choose **Download and install**. New here? Download **ADBHelper-Setup-x64.exe** below. Windows may show a SmartScreen notice for a new download; choose **More info → Run anyway**.
