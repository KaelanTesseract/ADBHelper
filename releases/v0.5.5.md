# ADBHelper 0.5.5

**Fishing** now catches far more fish: every spot is played at full speed, and spots are no longer skipped by mistake.

## Fixed

- From the second fishing spot on, ADBHelper saw only about one picture per second for the first few minutes, so most fish escaped. Every spot now runs at full speed (about 20 pictures per second).
- Some spots, such as **Packed Shoal**, start casting as soon as the rod is tapped. ADBHelper did not recognise this, reported the spot as not reached, and skipped the rest of the map. It now recognises the open fishing screen and fishes there.
- If the location arrow on the map could not be read, the rest of that map was skipped. ADBHelper now reads it a second time enlarged and, if needed, opens the map once more before giving up.

## Validation

- **210 automated tests passed**, together with formatting, Clippy, and license and advisory checks. Emulator runs fished every spot on Novaris until no attempts were left.
