## ADBHelper v0.5.5 is out! 🎣🐟

**More fish from Fishing**
Every fishing spot now runs at full speed, not just the first one, so far fewer fish escape. Spots that start casting right away (like Packed Shoal) are no longer skipped, and a hard-to-read map arrow no longer ends the search early.

Update from the green icon beside **Settings**, or download **ADBHelper-Setup-x64.exe** from GitHub.
