# ADBHelper 0.4.2

## Arena

- Fixed an early stop that could occur when the Challenge button showed available attempts. ADBHelper now reads the attempt count beside the ticket, so a display such as `5/1` is no longer mistaken for `0/1`.
- ADBHelper checks the overview title before using Challenge or Continue, so regular Arena and Supreme Arena are identified separately.
- Emulator testing reached the Battle button in regular Arena using an open attempt and verified navigation to the Supreme Arena overview. The test ended before battle start.
