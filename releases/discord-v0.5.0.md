## ADBHelper v0.5.0 is out! 🚀

📦 **Installer**
ADBHelper now installs like a normal Windows app: Start menu entry, no admin rights, uninstall in Windows Settings. Already using the EXE? Go to **Settings → Install ADBHelper → Install now**. Your settings and Daily routine stay.

🔒 **Signed updates**
Every update is checked against a signature before it installs. Update checks now run every six hours instead of every five minutes.

🐢 **Slow PC or emulator?**
ADBHelper notices it and waits longer by itself. Nothing to set up.

📝 **Log files**
**Settings → Log files → Open log folder**. Please attach today's log when you report a problem.

🛡️ **Guild Manager Scan**
Your API key is saved securely and no longer needs to be entered after every restart.

🎣 **Fishing (preview)**
Walks to fishing spots and plays the minigame. Still work in progress, so keep an eye on the emulator.

Update from the green icon beside **Settings**, or download **ADBHelper-Setup-x64.exe** from GitHub.
