# ADBHelper 0.5.2

ADBHelper now also finds older MuMu Player versions and tells you in the log why no device shows up.

## Connecting to MuMu Player

- Older MuMu Player versions (such as **MuMuPlayer 6**) install as `Nemu` with `vmonitor\bin\adb_server.exe`. ADBHelper now finds them as well, also directly under `Program Files` on any drive.
- ADBHelper tries every usual MuMu Player port (7555, 16384, 16416, 16448, 16480, 5555) whichever adb it uses.

## Clearer log when no device shows up

Every **Find devices** now writes to the log:

- which adb ADBHelper uses and where it found it, or that it found none,
- which MuMu Player port answered, or that none did,
- devices that adb lists but that cannot be used yet, with a hint: **offline** (restart MuMu Player, close other programs that bring their own adb) or **unauthorized** (allow USB debugging).

If you still see no device, please attach today's log file (**Settings → Log files → Open log folder**) to your report.

## Download

ADBHelper is now offered only as the installer **ADBHelper-Setup-x64.exe**. The file `ADBHelper-Windows-x64.exe` in the release is used by the built-in updater; please do not download it by hand. Older standalone copies keep updating and can switch with **Settings → Install ADBHelper → Install now**.

## Validation

- **175 automated tests passed**, together with formatting, Clippy, and license and advisory checks. New tests cover the older MuMu Player folder, device states such as offline and unauthorized, port answers, and the log lines.

## Update

Click the green update icon beside **Settings**, review the patch notes, and choose **Download and install**. New here? Download **ADBHelper-Setup-x64.exe** below. Windows may show a SmartScreen notice for a new download; choose **More info → Run anyway**.
